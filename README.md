# Novel Studio · 小说创作工坊

本地网页应用，用于管理小说设定、剧情线、大纲、正文写作和 AI 辅助创作。

## 运行方式

```bash
cd novel-studio
npm start
```

然后打开浏览器访问：

```
http://localhost:3737
```

> 需要 Node.js 22.5+（已使用 Node 内置 `node:sqlite`，无需安装 npm 依赖）。

## 功能

- 多部作品管理，完整层级：作品 → 卷 → 章节/场景
- 设定库：分类 + 标签 + 词条详情
- 正文内手动选中文字关联设定词条，悬停预览，点击跳转
- 全局搜索：设定 / 大纲 / 正文 / 角色 / 剧情线
- 剧情线：主线 + 支线，章节节点列表式全局预览
- 剧情线级角色状态，独立于全局人物档案
- 写作台：自动保存、字数统计、单栏 / 两栏 / 三栏切换、富文本排版
- 角色：基础档案、关系网、当前状态
- AI：DeepSeek（OpenAI 兼容）API 配置、连接测试、AI 写作 / 续写、AI 性格校对、AI 细纲生成
- AI 自动创建小说：输入一段描述，AI 自动完善设定并创建新作品，自动填充设定、角色、剧情线、大纲与首章草稿

## 数据

数据保存在本机 `novel-studio/data/novel.db`（SQLite）。API Key 也只保存在本机数据库中。
