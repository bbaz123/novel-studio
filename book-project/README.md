# 旧书修复室的四季

- 书籍类型：纪实随笔集
- 目标：把一间旧书修复室的四季写成可读的短篇纪实，让读者理解修复的边界
- 语言/受众：zh-CN / 对纸质书与手艺感兴趣的普通读者
- 章节数：4
- 来源：fixtures/ocb/source.md

## 目录

1. 春：第一本被救活的书（001）
2. 夏：浆糊、棉线与一张借书卡（002）
3. 秋：把顺序记下来（003）
4. 冬：修复不是复原（004）

## 产物说明

- `contract/`：任务契约与需求映射（生成即 schema 校验）
- `manifest/`：来源、章节、交付物清单（每项带 sha256）
- `chapters/<id>/`：contract / draft / review / commit 四件套
- `ledgers/`：术语、事实、时间线、伏笔账本（按章追加）
- `review/`：全书复审与风格追踪
- `reports/`：八部分报告
- `export/book.md`：已提交内容的导出（审批 hash 绑定）
