# 旧书修复室的四季

## 目录

1. 春：第一本被救活的书
2. 夏：浆糊、棉线与一张借书卡
3. 秋：把顺序记下来
4. 冬：修复不是复原

# 春：第一本被救活的书

修复室在西楼二层，窗外是一排樟树。春天的湿气最伤纸，开门的第一件事是通风，第二件事才是开灯。老周说，霉斑不是敌人，急着除掉霉斑才是。他先把书放进恒温箱，让水分慢慢退，三天后再碰浆糊。

# 夏：浆糊、棉线与一张借书卡

夏天要换浆糊。小麦淀粉煮到半透明，凉到不烫手，才能上纸。他教我把补纸的纤维对齐，宁可少补一寸，也不要多贴一层。多贴的那一层，五十年后会把原件揭下来。

# 秋：把顺序记下来

秋天的任务是拆装。一本线装书拆开有几十个算子，顺序一乱，誊抄的年月就丢了。老周用铅笔在无酸纸上画位置，每一撮都编号。他不相信记忆，只相信编号。

# 冬：修复不是复原

冬天读者来取书。那本书已经能翻开，纸色还是旧的，边角留着补过的痕迹。读者问，能不能修得看不出补过。老周说，看不出来不等于修得好，看得出来也不等于修得坏。
