## D6 · 删作品后，AI 埋点行怎么办（自审新发现）

| | |
|---|---|

| **影响** | A：全局指标随删作品而失真，且表无界增长；B：指标诚实、不动历史数据，但孤儿行仍无界增长；C：语义最一致，代价是失去"已删作品的 AI 使用史" |
