## 这份清单解决什么

第三章把三个**海澜市角色**（林清雪×2、陈牧野×1、苏晚晴×1）写进了江陵市的场景——大纲第八章才"第一次见到林清雪"、第十二章陈牧野才首现、苏晚晴是海澜三中班主任（第七章才转学）。已有的三层防线都没拦住：蓝图漏写阵容约束、出场角色卡自动把未来角色喂进了上下文、确定性预检没有"角色时点"这类判据。**在机制侧改动获得授权之前，这一层靠人工核对。**

## 每章交付前的核对步骤

1. 打开该章的**摘要 + 蓝图**，先圈出本章被允许出现的人名（蓝图 references / 约束里常已有"某某角色不出场"这类句子，第五、六章就是范例）。
2. 用上面的对照表逐个人名核对正文：**首现章号 > 当前章号 → 必须改**（删掉、改成已登场角色，或改为不具名的身份称呼）。
3. 看到任何新名字先停下：成文提示词里已有硬约束"不得引入未登记的具名角色/地点"。
4. 交付前跑一次确定性检查（编辑扫描 + 连续性预检）——注意现有预检的四类判据（角色卡时点 / 系统出场 / 篇幅 / 剧情线）**不含角色时点**，这一步目前只能靠本清单人工完成。

## 三层防线的现状（本轮实测）

- **蓝图约束**：有效，但逐章靠人写。第五、六章写了"海澜市角色一律不出场""不指定江陵三中班号"，第三章只写了"无新增具名角色与地点"，于是没拦。
- **出场角色卡（自动选角）**：`server.js:2169-2172` 的 0 分兜底会按名字序把**没人提过的角色**补进上下文（本次复算：岳宸炎64、林清雪28、李拓20、顾青山10、王磊10 为正分，兜底又补入陈牧野、江天启、深海母神）。林清雪能得分是因为第一章摘要里"全国直播"命中。
- **世界观层**：词条「境界体系（一至十阶）」原本点名苏晚晴等人 → 本次已加注"尚未登场角色，正文不得出场、不得点名"。
- **确定性预检**：仍是四类判据，未改动（机制侧改动需单独授权）。
