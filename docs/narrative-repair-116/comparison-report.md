# comparison-report.md｜"实际文本差异"与"质量核验"分开列

> 本轮的核心区分：**改动确实生效** ≠ **改得更好**。
> 下表左列是逐字可比对的文本差异（确定性事实），右列是质量观察（证据 + 不确定性 + 谁来裁决）。

## 1. A01：`职业方向——材料修复、灵植培育、检测辅助。` → `职业方向。`

| 维度 | 实际文本差异（SOURCE / VERIFIED） | 质量核验（ANALYSIS） |
|---|---|---|
| 逐字差异 | 被替换跨度 = `职业方向——材料修复、灵植培育、检测辅助。`（授权表登记 `p1s1~11`）<br>改后 = `职业方向。`<br>其余字符逐字不变（含段间换行、后续段落） | **不是格式错，是局部句意不完整**：删完只剩一个孤立的栏目名 |
| 系统给出的证据 | `information_truncation`（`subtype: orphaned_label`）：`label=职业方向`、`separator=——`、`lost=材料修复、灵植培育、检测辅助` | 提醒里点名了**具体丢了什么**（不是只报一个码），作者可以直接判断"后文是否已承接" |
| 处置 | soft 码，**不进** `HARD_CODES` → 改动仍进候选、仍显示在差异预览里 | **不建议自动采纳，需人工确认**；不强制回滚正式稿（E03-A4 明写"不强制用户必须保留完整职业列表"） |
| 两种合理候选（仅供作者） | ① 保留完整屏幕信息、压缩后文重复说明；② 确认后文职业事实完整承接后**整句删除**（而不是留半截标签） | 均由作者决定；系统只给候选与证据 |
| 回归 | `E03-1 / E03-1b / E03-1c / E03-1d / E03-1e`、`T16` | `E03-3b`（同类"能力："形态同样被抓到，判据不是为一条句子写死） |

| 维度 | 实际文本差异 | 质量核验 |
|---|---|---|
| 逐字差异 | 被删除跨度 = `耳机挂在脖子上晃，`；其余逐字不变 | **合理的局部精简**：不丢"等了十几分钟 / 从侧门挤出来 / 手里也捏着一张登记表" |

| 维度 | 实际文本差异 | 质量核验 |

## 5. 汇报口径（本轮交付能说什么、不能说什么）

- 能说：**越权不可通过**（已用安全攻击夹具在离线可复现）；**失败/无授权不扩大**（计划为空即不发起付费调用）；**A01 类型的信息删残可被指出并点名丢失内容**；**A02 类型的小幅精简不会被误拦**。
- 不能说：**整体自然度提升**、**AI 味降低**、**检出率/误报率达标** —— 这些需要独立授权的真实模型 A/B。
- 明确写：

```text
SKIPPED: paid_evaluation_not_authorized
文学效果：未进行真实模型 A/B，不能宣称整体自然度提升。
```
