## 1. 被替换掉的是什么（事故形态）

本轮样本里，模型为了让"中午测完"与"天黑出门"对得上，**替检测中心发明了一条叫号制度**：

```
下午的号按学校分批往下叫，他在外场又耽搁了一阵；走出检测中心大门的时候，天色已经暗了。
```

它的问题不是措辞，而是**事实来源**：

| 判据 | 命中 | 含义 |
|---|---|---|
| `new_workflow_rule` | ✅（证据"按学校分批"） | 这是本章此前不存在的新**制度性事实**（分批口径 + 下午还有一批人） |
| `temporal_causal_bridge` | ✅（`time_gap_unresolved`） | 底稿已收束（"测完…走了"）却把出门时间推到"天色已暗"，而新增内容**只**是无来源的流程声明 |

**结论**：它让时间"看起来对得上"，却没有建立"为什么这两个人测完还留着"的因果。
`assessTemporalBridge` 的放行通道是 `bridged_by_sourced_event` ——
**只有"点明了具体行为与具体对象"的等待事件才会被放行**。

## 2. 授权事件规格（交给作者落地）

### 2.1 必须满足的形态条件（判据口径，可自检）

一条合格的等待事件必须**同时**满足：

1. **有来源**：点名一个**具体行为** + **具体对象/量词**（判据词形：`陪|等|排队|找到|补交|复核|重新|被叫|叫到|进去|出来` … `单|人|趟|次|号|遍`）。
2. **落在同一场景**：它必须发生在检测中心内外场，不能跳去别的地点再回来。
3. **不新增制度事实**：**不得**再出现"按 X 分批 / 分时段 / 分学校 / 按批次叫号"这类机制声明。
4. **不叠加第三个时间锚**：傍晚锚点只保留一处（原文已写"天色已经暗了"），不要新增第二个墙面钟。

### 2.2 反面样例（会被判据拦下的写法，**不要用**）

| 写法 | 命中判据 | 为什么不行 |
|---|---|---|
| `下午的号按学校分批往下叫，他在外场又耽搁了一阵；` | `new_workflow_rule` + `temporal_causal_bridge` | 新制度事实 + 无来源等待 |
| `他在外场等了一会儿，天就黑了。` | `temporal_causal_bridge` | "等了一会儿"没有对象、没有来源，等于把缺口换个说法 |
| `检测效率比往年慢了不少，所以拖到傍晚。` | `new_workflow_rule` | 又发明了一条制度性说法 |

### 2.3 正例（判据已实测放行的形态）

判据的实测正例是这一形状 —— **动宾 + 量词**，且事件是人物自己做的事：

```
他陪着王磊又把排号单交回去复核了一趟；走出检测中心大门的时候，天色已经暗了。
```

`assessTemporalBridge` 对它的判定是 `bridged_by_sourced_event`（`resolved: true`），
即**放行**：等待有了来源（陪人 + 交单 + 复核 + 一趟），时间推进就不再是凭空发生。

> ⚠️ **这一条是判据侧的正例，不是我替作者写的稿。**
> 具体写什么事件（陪谁、办什么事、用多久）**由作者定**；上面的句子只用来证明
> "什么样的形态能被判据接受"。作者落地的句子应当来自蓝图/角色卡/事件账本里**已经存在**的事。

### 2.4 待作者确认的唯一缺口

判据需要一个**归入本章既有设定的**事件素材。本轮上下文里能确证存在的只有：

- 检测流程本身（被叫名 → 上台 → 按检测石 → 等级播报）；
- 评定单/排号纸这类物件（正文出现"评定单上是一串数字"）。

**除此以外我手上没有本章蓝图与角色卡**，因此**不能**替作者编一个"有来源"的事件
（编出来的正是本轮事故的那种东西）。请作者用下面任一方式补齐：
