# v118 0317 专项 · 审稿质量报告（review-quality-report）

> 定位：这是一份**独立于实现的**审稿质量评估——判断的不是"代码写没写对"，而是
> "这套判据能不能真的帮作者看清：审稿事实是否真实、修改后问题是否仍成立"。
> 与 `implementation-report.md` 的分工：那边记录改了什么，这边记录**收益、误报风险与没做到的部分**。

## 1. 本轮样本的审稿质量实测（SOURCE）

| 维度 | 实测结论 | 证据 |
|---|---|---|
| 报告引文的真实性 | **不成立**：两条被引号标为原话的台词在正文里根本不存在 | 「你就不能配合一下气氛」「你先上去吧」→ `quote_not_found`（V118-06/07） |
| 真实引文是否被误伤 | **不会**：逐字命中的引号通过；不带引号的概括不进入核验 | V118-08 / V118-08-b |
| 报告优点与正文是否自洽 | **部分不成立**：绝对局限措辞与正文反例并存 | 「完全没有内心独白」×「他从小觉得…」（V118-09） |
| 修稿后"问题是否真的解决" | **无法由现有证据支持**：三处只删了一小部分 | R01 / R02 / R07 均为 `partially_resolved` |
| 未选中问题是否被误判 | 旧实现会让它们**消失**（既非已改也非失败） | V118-11（探针实测 `count:0` 且无任何说明字段） |
| 场景反应的因果匹配 | **旧判据对真句完全失明** | 「外场安静了」不在 `UNIVERSAL_HEAD` 词表内 → 零候选（V118-15） |

**一句话**：这次审稿报告里**同时存在**"虚构原文""绝对化好评"与"把删短语当成解决问题"三类可信度问题，
它们都不是文学判断分歧，而是**可逐字核对的归属错误**。

## 2. 本批判据的收益

1. **把"新增制度"从纯表达里拿出来**：此前「按学校分批」会被自动应用；现在它会落到 `story_fact`
   并附 `needs_fact_authorization`，作者至少能看到"这条改动替你发明了一条叫号规则"。
2. **让"旧引文消失"不再自动等于"解决"**：`coverageVerdict` 补上了这一层；
   这是本批对"作者被虚假完成度误导"最直接的一处修复。
3. **行内引号第一次进入核验**：`summary / strengths / issues` 的引号内容此前完全没有归属检查。
4. **未处置项第一次成为显式状态**：`unaccounted` 让"我这条没选"不再伪装成"这条没变化/改失败"。
5. **补上一条静默失效**：`reaction_causality` 的现场地点词缺口（零候选 = 看起来没问题）。

## 3. 误报风险与防线（逐条）

| 判据 | 主要误报形态 | 本批防线 | 断言 |
|---|---|---|---|
| `new_workflow_rule` | 把普通叙述里的"分批"当制度；对已批准机制反复硬拦 | 只看新增片段 + 必须同现叫号语 + `baseText` 已含同一机制即放行 | V118-01/02/14 |
| `temporal_causal_bridge` | 把任何时间推进都当缺口 | 必须"底稿已收束 + 墙面钟"同现；有来源的等待事件放行 | V118-03-c |
| `auditReviewQuotes` | 把概括性转述当引文核验 | **只**核验引号内容；引号边界剥除但不归一台词内部 | V118-08-b |
| `strength_qualifications` | 按硬词表机械报 | 只在**能指出正文反例**时报；只给限定建议，不改 status、不删句 | V118-09-c |
| `prop_state_possible_overlap` | 把常态动作当冲突 | 同物件 + 不同状态 + 中间无复位；带 `counterevidence` | V118-10-d |

## 4. 仍然不足的地方（如实）

1. **语义层未跑**：所有"改动后阅读效果是否变好"的判断都停在 `not_run`。
   本批把这一点变成**显式状态**，但没有、也不能替语义判断作结论。
2. **`coverageVerdict` 尚未接线**：它已被导出、可断言，但界面还没消费它；
   在接线之前，"作者看到 resolved"这件事**还没有真正改变**——改变的是契约与离线证据。
3. **没有真实任务快照**：因此本报告不对"为什么这次只改了五处"作任何因果断言
   （不把模型的文字当成已发生事实）。
4. **`strength_qualifications` 的覆盖是窄的**：只认"完全没有/唯一/一律"这几类绝对措辞，
   以及"解释"与"内心"两族反例。更细的绝对断言（例如"没有一处抒情"）仍会漏。
5. **`propStateCandidates` 依赖句切分与相邻 3 句窗口**：跨段较远的同物件状态异常仍会漏。
6. **`new_workflow_rule` 是词形判据**：真正"换一种说法"的新机制（例如"按考点分流"）
   若不含 `分批/分时段/分组` 这类字样，仍可能漏。这是刻意的窄口径（零误报优先）。

## 5. 结论

- 对"审稿事实是否真实"：**有实质改善**——引文归属第一次进入核验，且不误伤概括。
- 对"修改后问题是否仍成立"：**只修了防误报的那一半**（不再自动叫 resolved）；
  真正判定仍待语义层，未跑就是未跑。
- 对"有没有添加未授权故事事实"：**有实质改善**——未批准的制度与时间因果会落到 `story_fact`。
- 对"作者批准的范围是什么"：本轮**没有**真实补丁可审（`approved_hotspots` / `applied_diff` 为空），
  这一栏如实留空，不用机制改动冒充补丁审计。
