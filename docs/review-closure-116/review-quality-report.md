## 2. 报告自洽（任务书 §1.3 的四处矛盾）——本轮新增可检测能力

| 矛盾 | 判据 | 正例 | 反例（必须不报） |
|---|---|---|---|
| 优点"0001号之后同类机制不再完整演示" vs 问题"0372号重复全套" | 绝对措辞（`不再…`／`(完全|彻底|根本|基本)(没有|没|无|不存在|不)`／`零…`／`从未|从来没有|毫无|没有任何`）+ 同话题 | **契约修正（2026-10-11）**：这类重叠只进 `advisories`（建议核对），**不改 status**；**T05-a** 已按新契约改述，**T05-b** 是把真实假阳性钉住的回归 | **T06-b**：优点谈"排队布景"、问题谈"结尾重复"（不同话题）→ `status:'ok'`，**不报** |
| 优点"伏笔完全没有解释" vs 正文有 `他从小就觉得……` | 绝对措辞 + strength 明确在说"解释/说明/交代" + 正文存在解释性连接词句 | **T06-a** → `needs_calibration`，**并给出反例原句** `他从小就觉得…` | 无解释句时**不报**（`explanationExample` 返回空 → 提前返回） |
| "扫描命中的都必须提" vs 把 `微微`/`嘴角` 当 AI 腔证据 | 扫描命中已降为候选（S01） | T02-b | T02-a：合法 `微微` 语义上可 keep |
| 角色卡时点问题混进正文修稿 | `target_scope: character_card` 分流 | R08 口径 | 不产生 chapter patch |

> 为什么要在**确定性层**做：模型两次都用绝对措辞，它很少自己发现；而作者会同时看到两句互相否认的话。
> 本层**不新增模型轮**，只做词面核对，**不改写**任何结论。
>
> ⚠️ **能力边界（2026-10-11 用真实数据校准后确定）**：只有"绝对措辞 × **正文反例**"这一种能置
> `needs_calibration` —— 因为它能给出**可核对的证据**（那句原文）。优点与问题之间"字面话题重叠"
> **不足以证明语义矛盾**（在 12 份真实报告上宽松判据误报 6 份、收紧后又让合成正例漏报，
> 说明不存在同时满足的字面阈值），因此降级为 `advisories`（建议核对、不改 status）。
> **呈现层同样要区分措辞**：conflicts 说"互相否认"，advisories 只说"建议核对"（见 `app.js` 的
> `reportConsistencyHtml`，两档都渲染、措辞强度不同）。

## 3. M01–M03（漏审与保护对照）——本轮新增两类诊断

### M01 场景反应可信度 → `reaction_causality`

| 项 | 内容 |
|---|---|
| 疑点（SOURCE） | D 级本来常见，主角 D 级却使"靠在墙边打盹的考生全都停住了"；"手机屏幕的反光……停住了"不合逻辑 |
| 判据 | 全体量词出现在**分句开头** ∧ 带中止动作（停住/静/愣） ∧ 语境已把成因标为**普通**（本来/常见/平常…） ∧ 本句**不是**奇观 ∧ 非对白 |
| 正例 | **T21-a**：`他的成绩是C级。C级本来就常见…` + `可大厅里安静了。靠在墙边打盹的考生全都停住了。` → 出候选 |
| 反例（必须不报） | **T21-c**：`直播画面里，S级异象的光柱冲上云层。` + `候检大厅里没声了。全场抬着头。` → **不报**（奇观足以支撑强反应） |
| 反证通道 | 候选自带 `counterevidence_hint`：「若该等级/事件被反复铺垫为异常，或这是有意的舞台化描写，反应规模就成立」 |
| 边界 | 候选 `suggested_action: 'check'`、`requires_semantic_check: true`；**绝不**据此重写全场反应 |

### M02 视点/触觉 → `focalization_limit`（触觉越界）

| 项 | 内容 |
|---|---|
| 疑点（SOURCE） | 固定石板仅手按一下就断言"密度比普通石头高" |
| 判据 | 同段内触觉动词（按/摸/抚/捏/抵/触/握/攥）与"触觉得不到的性质"（密度/硬度/材质/成分/重量/内部结构…）**邻近 ≤40 字** |
| 正例 | **T22-a**：`他把右手按在石板上。石板的密度比普通石头高。` → 出候选，证据写明"触觉动词「按」之后紧接断言「密度」" |
| 反例 | 若性质本可由触觉得到（温度/震动）→ 判据不含这些词，**不报** |
| 反证通道 | 「若角色有已确立的特殊感知（系统提示、特殊天赋、专业训练），则不成立」 |
| 关键边界 | **不自行赋予主角能力**：T22-c 断言候选里不出现"新增/赋予/获得能力" |

### M03 视点/触觉 → `focalization_limit`（隔距离）

| 项 | 内容 |
|---|---|
| 疑点（SOURCE） | 隔着队伍说李拓"掌心还残留着一点金色的余温" |
| 判据 | 同段内**距离标记**（隔着/远处/对面/另一头/隔了/千米/公里/米外）∧ **感知动词**（知道/明白/感觉/看出/察觉/残留…） |
| 正例 | **T22-b**：`他隔着队伍看了一眼李拓，李拓掌心还残留着一点金色的余温。` → 出候选，证据给出"隔着距离却用「残留」给出对方身体上的信息" |
| 反例 | 若信息本可来自**可见线索**（光效、声音、表情）→ 反证通道明写"观察来源就成立"，作者/模型可判 keep |
| 关键边界 | 任务书要求"核对是能看到金光还是能感到余温，**不强行改掉合理描写**" → 判据只提单点，不改写 |
