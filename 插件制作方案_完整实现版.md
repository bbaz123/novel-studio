# DeepSeek Harness 0.2.0-rc.2 自安装插件管理器插件完整实现方案

> 基于 DeepSeek Harness 的 Everything is a Plugin 架构设计。Harness
> 项目本身采用插件化架构，0.2.0-rc.2 为本方案目标适配版本。\
> 参考项目：deepseek-ai/deepseek-harness

------------------------------------------------------------------------

# 第一部分：项目目标

开发系统插件：

    dsh-self-plugin-manager

实现：

-   设置界面新增「自安装插件」
-   自动扫描用户插件
-   插件运行健康检查
-   宿主版本兼容判断
-   自动适配更新
-   更新失败自动回滚
-   更新完成自动进入验证会话
-   自动选择最低成本模型进行验证
